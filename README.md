# Personal Expense Tracker

A full-stack web application for recording, categorizing, and reviewing personal expenses.

## Features
- User authentication
- Expense and category management
- Dashboard charts and reports
- User and administrator areas

## Stack
HTML, CSS, JavaScript, Node.js, Express, MongoDB, JWT, and Chart.js.

## Run locally
```bash
cd backend
cp .env.example .env
npm install
npm run dev
```

Set your own strong environment values. Never commit `.env` files or credentials.

Serve the `frontend` directory with a local static server and open `public/index.html`.

## Project structure
- `backend/` — API, models, routes, and middleware
- `frontend/` — public, user, and administrator interfaces
- `docs/` — project documentation
